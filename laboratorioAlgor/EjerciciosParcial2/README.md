# Ejercicios Parcial 2

Aquí entregas tus ejercicios del segundo parcial mediante un **pull request**.

## Estructura

Crea una carpeta con tu **matrícula** y coloca dentro tus archivos `.alg`:

```
EjerciciosParcial2/
└── 0000721/
    ├── problema-01.alg
    └── problema-02.alg
```

Solo modifica archivos dentro de **tu** carpeta.

## Pasos para entregar

1. En GitHub, abre el repositorio y presiona **Fork** para crear tu copia.
2. Clona tu fork:
   ```
   git clone https://github.com/TU_USUARIO/isirprogramacion.git
   cd isirprogramacion/laboratorioAlgor/EjerciciosParcial2
   ```
3. Crea tu carpeta y tus archivos:
   ```
   mkdir TU_MATRICULA
   ```
4. Guarda y sube tus cambios a tu fork:
   ```
   git add TU_MATRICULA
   git commit -m "Parcial 2 - TU_MATRICULA"
   git push
   ```
5. En GitHub, en tu fork, presiona **Contribute → Open pull request**.
   - Título: `Parcial 2 - TU_MATRICULA - Tu Nombre`
6. El profesor revisará tu pull request y te dejará comentarios. Si te pide cambios,
   corrígelos en tu fork y haz `git push` de nuevo: el pull request se actualiza solo.
